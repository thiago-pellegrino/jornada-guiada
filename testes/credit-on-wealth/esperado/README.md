# Saídas esperadas

Depois do primeiro teste aprovado, grave aqui o `saida.json` de cada capacidade como `{capabilityId}.json`. Quando a versão de uma capacidade mudar, rode o teste de novo e compare a saída nova com a daqui antes de publicar a capacidade.

Ainda vazio: o teste ponta a ponta depende de a plataforma, ou um executor das capacidades, estar disponível.
